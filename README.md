# 🎛️ LED Brightness Control Circuit

An analog DC-powered circuit designed in *LibrePCB* to manually adjust LED brightness. This project serves as a hardware prototype demonstrating analog voltage/current control using a potentiometer, safety resistance, and visual indication.

---

## 🛠️ Hardware Components

* 🔋 *Power Supply:* Power DC Battery
* 🎛️ *Analog Control:* Potentiometer (Variable Resistor)
* 🛡️ *Protection:* $330\,\Omega$ Protection Resistor
* 💡 *Indicator:* Indicator LED

---

## 🚀 Usage

1. Clone or download this repository.
2. Open the .lppz project file in *LibrePCB*.
3. View or edit the schematic, board layout, and 3D renderings!
